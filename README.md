# Spider vs Human: Ночь каракурта

Игра для ПК с мышью. Переживите десять волн и защитите шалаш.

WASD: движение, мышь: обзор, ЛКМ: огонь, R: перезарядка, 1–5: оружие, E: ремонт/турель, Q: патроны у верстака, Shift: бег, Space: прыжок, Esc: пауза и патроны, M: звук. Покупки доступны у верстака во время подготовки. Enter: удерживайте 1 секунду, чтобы досрочно начать штатный отсчёт; отпускание отменяет удержание. Со второй волны в бою появляются припасы: подойдите к ящику со световой меткой, чтобы получить детали. Указатель помогает найти припасы вне поля зрения; дуга у прицела показывает направление полученного урона.

Three.js r180 загружается с jsDelivr. WebGL и Pointer Lock обязательны.

Это веб-сборка. Авторские исходники Blender хранятся отдельно у владельца проекта.
