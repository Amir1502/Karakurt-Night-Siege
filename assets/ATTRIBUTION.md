# Spider vs Human: Ночь каракурта

Models, material atlases and game scenery are original artwork authored for this project.
The editable Blender sources and generation scripts are in `art/blender/` in the source delivery.
Gloved hands, pistol and shelter reuse the project's original trial artwork, with its matching atlas UVs.
Five animated spider species and the other weapons, sentry and camp props were authored in Blender 5.2.3 LTS.
Sand and soft particle textures were authored locally using Blender's bundled NumPy.

The separate user-provided robot and static tarantula imports are not part of this runtime bundle.
No external stock models, paid generation services or external texture libraries are used by these assets.
Project artwork is delivered to the project owner; no third-party redistribution license is implied.
